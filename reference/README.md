> 本项目的原始厂商文件放在 `source/`（`SBX7_PCDRV_L9_1_02_03.exe`、`SBX7_PCFW_EN_200321.exe`），已在 `.gitignore` 中排除；`reference/` 保留给额外截图、说明与授权材料。

## 放什么

- 用户提供的安装包、样本、截图、录屏、页面快照或导出文件。
- 用户提供的目标路径、URL、包名与版本说明。
- 授权证据：用户声明、书面许可、测试环境说明。
- Clean-room 重建可用的可见材料：截图、可见文本、布局、颜色、字体、间距、菜单行为。

不要放：反编译代码、符号表、文件清单、REA Deep 发现，或任何未授权的目标内部数据。

## 命名与哈希

```text
reference/<subject>-<date>.<ext>
reference/README.md
```

每个文件记录：

- 来源：用户提供 / 授权范围内采集。
- 采集时间与工具。
- SHA-256。
- 授权依据与允许用途。
- 与哪些 Evidence 相关。

## 规则

- 只读：不要修改、覆盖或重新编码用户提供的原件。
- 不提交目标数据：`.gitignore` 默认排除 `reference/*`，只保留本文件。
- 需要转换格式时，另存为新文件并记录转换命令，不覆盖原件。
- 与他人共享前先脱敏；删除账号、设备标识、个人信息与内网地址。
- 授权撤回时停止使用并按用户要求删除。

## 与 Evidence 的关系

`reference/` 是输入材料，`evidence/` 是从目标或材料得到的证据。引用参考材料时，在 Evidence 中写明路径与 SHA-256；不要把参考材料本身当成观察结论。
